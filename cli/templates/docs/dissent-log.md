# Dissent Log

> Record architectural disagreements that were raised but not resolved in the current slice.
> This is optional input for the Validation Agent.

## Template

```
- **Date:** YYYY-MM-DD
- **Slice:** <slice-id>
- **Topic:** <what is contested>
- **Position A:** <summary>
- **Position B:** <summary>
- **Status:** open | resolved | deferred
```
