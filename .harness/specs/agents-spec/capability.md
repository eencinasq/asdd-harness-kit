# Capability: Agent grammar, single roles, and projected tool envelopes (agents-spec)

## Category
IMPROVEMENT

## Scope
- Pitch ID: ad-hoc
- Scope ID: none
- Scope class: must_have

## Problem Statement
The ASDD subagents (`cli/agents/asdd-*.md`, `cli/modules/{bruno,playwright-e2e}/*.md`) are phase prompts, not bounded
actors: they carry rules that contradict `AGENTS.md` (hand-written manifest), mix authoring and auditing (QA writes the
tests it then judges; Knowledge custodies state, spikes, and re-triggers agents), run with every tool of the runtime
(auditors can edit what they audit), and lack routing boundaries, escalation and convergence gates. Squads get agents
that can silently overreach.

## Business Context
Every installed project receives these agents through runtime links; a defect reaches every squad and every runtime.

## Actors
- ASDD agent (the 13 shipped + the new spike researcher): runs one phase role.
- Parent session (developer's runtime): routes to an agent by its description.
- Installer (`asdd install`): writes the agent files each runtime reads.
- Kit maintainer: runs `npm test`.

## Domain Entities Involved
- Agent definition: canonical `.agents/agents/<name>.md` with frontmatter (`metadata`, `capabilities`, `limits`).
- Runtime agent file: `.claude/agents/`, `.cursor/agents/`, `.opencode/agents/` (rendered) or a link (other runtimes).
- Session, manifest, registry (generated by `asdd sync`).

## Functional Scope (Behaviors)
- Agents state trigger, negative boundary, tier, boundaries, decision rights, ground truth, I/O contract, negative space,
  convergence and escalation gates.
- QA audits only; implementation's TDD writes tests; validation alone reviews requirements; a researcher does spikes.
- The installer renders tool envelopes per runtime from `capabilities`.
- `asdd kit agents-lint` gates the grammar.

## Out of Scope
Renaming agents; gate numbers; canary routing; projection for kimi, junie, devin, kiro.

## Non-Functional Requirements
### Performance
Lint and render are pure Node, no network.
### Security
Auditors lose the edit tool on Claude Code and OpenCode; non-orchestrators cannot spawn subagents there.

## Success Metrics
`asdd kit agents-lint` exits 0; an installed project's `.claude/agents/asdd-validation-agent.md` lists no `Edit`/`Agent` tool.
