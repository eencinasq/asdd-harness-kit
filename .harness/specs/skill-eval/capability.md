# skill-eval — Capability (backfilled from spec.md on escalation)

**Author:** asdd-lite-agent
**Model/Tool:** Devin (SWE-2 Flash Medium)

## Intent

Measure what a skill or agent *does*, not only how it is written. Today `asdd kit skills-lint` / `agents-lint` check
grammar and `converge-eval` scores EARS fixtures; nothing proves that a changed skill still produces the expected
outcome on real tasks. Add `asdd skill-eval`: per-skill task fixtures, a before/after comparison against a baseline,
and regression reporting (P5 roadmap, gap G16). Escalation is likely if the runner needs a model adapter per runtime.

Mapped: `cli/src/harness/skill-eval*.mjs` (with `skill-eval*.test.mjs`), `cli/eval/skills/**`, `cli/src/harness/commands.mjs` (one entry), `package.json` (`test` script entry), `cli/versions.json` (regenerated by `asdd kit versions`), `README.md` (command row)

## Capability

The harness gains a deterministic skill-evaluation command: task fixtures per skill under `cli/eval/skills/<skill>/`,
execution of declared probes in a sandboxed workspace, assertion of observable outcomes (files, commands, exit
codes), pass-rate reporting per skill, optional before/after comparison against a git ref for the skill body, and
non-zero exit with named regressions. No LLM-as-judge in the gate path; no model or runtime adapter required.
