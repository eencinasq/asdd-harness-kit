# intent-intake — Spec (lite)

## Intent

P6.4 (gap G26). Engineers pick an Intent from the tracker and start work on their machine with any coding agent.
Today `external-trackers` imports a pitch into `handoff.yaml`; nothing imports an intent. Add the intake flow: the
agent reads the Intent item through the tracker MCP; a deterministic, offline `asdd intake --from <file|-> --ref <url>`
validates the canonical format, writes `.harness/specs/<slice>/intent.md`, runs `slice init` in the suggested mode,
and records the tracker source. Grounding is re-checked against the current code at intake (code may have moved since
shaping), and an `intent-evidence` validator in `asdd check` keeps every intent's evidence refs resolvable.

Mapped: `cli/src/harness/intake.mjs`, `cli/src/harness/intake-lib.mjs`, `cli/src/harness/intake-lib.test.mjs`, `cli/src/harness/validators/intent-evidence.mjs`, `cli/src/harness/check-invariants.mjs` (validator wiring), `cli/src/harness/commands.mjs` (one entry), `package.json` (`test` script entry), `cli/skills/external-trackers/SKILL.md`, `cli/skills/external-trackers/references/**`, `.agents/skills/external-trackers/**` (copies), `cli/versions.json` (regenerated), `README.md` and `cli/README.md` (command rows), `cli/src/harness/init-slice.mjs` and `cli/src/harness/init-slice.test.mjs` (`--source-json`: the `source` block of the `001` session), `cli/scaffold/config/project.schema.json` (source) and `.harness/config/project.schema.json` (copy, `asdd kit self`) for `drift.intent_evidence`, `cli/scaffold/config/README.md`, `.harness/config/README.md` (copy), `cli/steering/skills.md` and `.harness/steering/skills.md` (skills index, regenerated by `asdd kit self` when the external-trackers description changes)

## Requirements

- **REQ-001.** `asdd intake --from <file|-> --ref <url>` shall reject an item that does not follow the canonical Intent format and name the missing fields.
- **REQ-002.** For a valid item it shall write `.harness/specs/<slice>/intent.md`, initialize the slice in the suggested mode (`hotfix`, `lite`, or `full`), and record the tracker URL as the slice source; it shall not use the network.
- **REQ-003.** At intake, every grounding evidence ref that no longer resolves (missing REQ, slice, or path) shall be reported, and the intake shall stop unless `--accept-stale` is given.
- **REQ-004.** `asdd check` shall report, through an `intent-evidence` validator, intents whose grounding refs do not resolve (WARN by default; FAIL when the binding says so).
- **REQ-005.** `external-trackers` shall document the intake flow and hand off to the slice's first phase.
