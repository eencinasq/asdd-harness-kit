# Knowledge — process memory (mandatory when indexed)

**Source of truth for what the squad already knows.** Index: `.harness/knowledge/`
(regenerated by `asdd sync`; manual: `asdd knowledge sync`).
Agents and skills query it with `asdd knowledge` (JSON on stdout; exit 1 when there is no index):

| Command | Use |
|---------|-----|
| `search "<query>" [--k 5] [--slice <id>]` | Semantic/lexical search over every REQ, spec section, feature, session, and log — **"does this already exist?"** |
| `trace <node-id> [--depth 2]` | Graph BFS from any node: REQ→spec→feature→file, DEPENDS_ON chains, sessions |
| `slice <slice-id>` | JIT bundle: slice node + spec docs + REQs + features + session/log counts — **context pack without opening files** |
| `status` | Index freshness, counts, active backend (sqlite/jsonl), search mode, and `warnings` when the index is degraded |
| `patterns [--status <s>]` | Learning loop: repeated failures, overrides, and dismissals grouped as `LP-*` patterns with their `SP-*` proposals and measured effect. Computed live; needs no index ([Learning Gate](./quality-gates.md#learning-gate)) |

The `knowledge` MCP server (`tools/knowledge/`) exposes the same five queries as `knowledge_*` tools for people in chat; it vendors this script, so the answers match.

Node ids: `slice:<id>`, `req:<slice>:<REQ-…>`, `ac:<slice>:<AC-…>`, `feature:<slice>:<TASK-…>`,
`spec:<slice>:<doc>`, `file:<path>`, `session:<slice>:<file>`, `log:failure_log`, `log:dissent_log`.

## Per-role usage

- **Discovery / Shape Up / Product Delivery:** `search` for overlapping or
  prior capabilities before scoping; `trace` on related slices for
  DEPENDS_ON conflicts; `status` to confirm the index is fresh.
- **Spec / Validation:** `search` for duplicate REQs and prior AC wording;
  `trace` to verify REQ↔feature traceability claims.
- **Task Planning / Implementation:** `slice` for the context pack;
  `trace` on task nodes for DEPENDS_ON order and OWNS file scopes.
- **QA / Refactor:** `trace` for coverage (REQ→feature→file);
  `search` for similar past failures (`log:*` nodes).
- **Knowledge:** `patterns` for open patterns before closing a slice (QG-LEARN-04).
- **Knowledge Agent:** all of them — dedupe detection, blast radius, failure mining.
  It also runs the `codebase-audit` skill, which uses `trace file:<path>` on hotspot
  files ([spec-drift.md](./spec-drift.md)). Feature nodes carry `evidence_hash`.

If `status` reports no index or a stale `generated_at`, run
`asdd knowledge sync` once before relying on results.
