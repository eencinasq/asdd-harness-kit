# Mutex locks (DEPRECATED in v3.0)

The v2 lock protocol (`<slice-id>.lock` files) has been replaced by append-only session logs in v3.0.

Concurrent work is now safe because:
- Session logs are append-only (each writer creates a new file)
- Manifests are generated by `sync-state.mjs`
- Feature scopes are validated by `check-invariants.mjs`

This directory is kept for backward compatibility during migration. No new lock files should be created.
