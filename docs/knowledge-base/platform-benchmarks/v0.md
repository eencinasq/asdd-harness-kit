# Platform Benchmarks v0 — Hook Cold-Start Evidence (platform v0 §5)

**Status:** measured evidence, not a language decision (`Q-R7` stays human-owned).
**Hardware:** `darwin arm64` · Apple M2 Max · `node v26.13.1` · method `spawnSync` wall-time, reps=20, same `{"command":"npm test"}` gate payload per target — `node cli/test/conformance/bench.mjs [--reps N] [--json]` reproduces.

## Results

| Target | p50 | p95 | min | Note |
|---|---|---|---|---|
| `asdd gate` (hook payload, node) | 116.59 ms | **125.59 ms** | 110.89 | the latency every fail-closed Cursor/Claude hook pays per shell command |
| `asdd --version` (node) | 116.07 ms | 124.46 ms | 110.00 | boot floor — confirms `gate` cost ≈ interpreter boot, not gate logic |
| `asdd verify` (hook payload, node) | 592.14 ms | **621.16 ms** | 573.36 | spawns `check-invariants` inside → double Node boot per Stop |
| spike gate-payload (go 1.x) | 3.97 ms | 15.25 ms | 2.95 | minimal binary — bounds cold-start delta only |
| spike gate-payload (rustc -O) | 3.42 ms | **6.88 ms** | 2.07 | |
| spike gate-payload (clang++ -O2) | 2.73 ms | 7.19 ms | 2.28 | |

## Reading

- The proposed `<15 ms` hook budget (v0 §5) is reachable natively: rust/cpp spikes clear it ~2×; go sits at the boundary (15.25 ms p95 — spike is trivially small; real gate logic adds work on both sides).
- Node pays ~125 ms per `gate` invocation and ~621 ms per `verify` — the interpreter boot dominates; gate logic is noise beside it. A native executor removes this per-invocation tax on every shell command the agent runs.
- Spikes carry **no ASDD semantics** — they bound the interpreter-vs-native cold-start delta. The real delta narrows by whatever the ported gate logic costs; the conformance suite (not benchmarks) proves parity.
- `verify`'s cost is structural: hook → executor → check-invariants child = two interpreter boots. A native executor collapses the outer boot; validator cost remains measurable via the telemetry `sensor` span.
