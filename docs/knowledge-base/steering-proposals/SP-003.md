## Pattern

- **Pattern:** LP-b5774134 (`failure:drift:done-slice-features-reopened`, escape)
- **Occurrences:** 5
- **Slices:** jev-module

Evidence:

- Editing scripts/test-install-into.sh (jev-module TASK-001) reopened passing features of the DONE slice kit-hygiene through DRIFT-02; jev-module could not mark features passing until the old slice was re-verified.
- Editing scripts/install-into.sh, package.json (jev-module TASK-003) reopened passing features of the DONE slice kit-hygiene through DRIFT-02; jev-module could not mark features passing until the old slice was re-verified.
- Editing scripts/test-install-into.sh (jev-module TASK-001, log-leak assertions) reopened passing features of the DONE slice kit-hygiene through DRIFT-02; jev-module could not mark features passing until the old slice was re-verified.

## Root cause

DRIFT-02 compares every `passing` feature's `scope_paths` with the commits after its `evidence_commit`, for every slice, including slices whose status is `DONE`. Shared files (`scripts/test-install-into.sh`, `scripts/install-into.sh`, `package.json`, shared docs) belong to features of the finished kit-hygiene slice, so every later slice that edits them reopens historical features. In jev-module this happened five times; each time the invariants failed until the old slice was re-verified, which blocked marking jev-module features `passing`. The re-verifications never found a defect: the later slice's own tests already covered the change. For a DONE slice the evidence is historical, so this is sensor noise even though the signals are logged as failures.

## Change

In `cli/src/harness/drift-lib.mjs`, compute DRIFT-02 only for features of slices whose status is `in_progress` (skip `DONE`, `PARKED`, `ABANDONED`). Add a test: a DONE slice whose owned file changes after `evidence_commit` produces no DRIFT-02, and an in-progress slice still does. Document the rule in `.harness/steering/spec-drift.md`.

## Success criterion

No failure-log entry with signature `drift:done-slice-features-reopened` across the next 10 sessions, and the new test shows DRIFT-02 still fires for in-progress slices.

## Rollback

Revert the status filter in `drift-lib.mjs` and its test.
