# Knowledge Base

Project-owned operational knowledge, maintained by the Knowledge Agent.

- `steering-proposals/` — `SP-NNN.md` changes to a guide, sensor, or code, one per learning pattern (`asdd learn --propose <LP-id>`; the Tech Lead decides); also holds the vendored ratified steering proposal (`vN.md` + `vN.review.md`)
- `rules-proposals/` — vendored snapshots of the ratified rules proposals (`vN.md` + `vN.review.md`); contract docs cite these, never the source vault. Update only when a newer proposal version converges
- `profiling-proposals/` — vendored snapshots of the ratified harness.profiling proposals; same update rule
- `slices/` — per-slice completion notes and lessons
- `spikes/` — research spike outcomes
